# Stage 2 正式结果分析

## 核心结论

TabICLv2 替换 DML 中的传统干扰函数学习器后，并不是在所有数据结构上都更好。最准确的结论是：

> TabICLv2 在平滑非线性场景中同时提高了处理效应估计精度并大幅减少运行时间；在线性场景中与最优传统方法基本持平；在树型非线性场景中明显弱于 XGBoost 或 Lasso，并出现严重的置信区间欠覆盖。因此，TabICLv2 是有条件的改进，而不是传统 DML 学习器的通用替代品。

49 个“配置×模型”组合均基于 100 次蒙特卡洛重复。不同模型在同一次重复中共享数据种子和交叉拟合种子，因此可以进行配对比较。

## 分场景结果

### 1. 平滑非线性场景：TabICLv2 明确占优

三个 smooth 配置中，TabICLv2 全部击败该配置下最好的传统模型：

|配置|最佳 Tab 模型 RMSE|最佳传统模型|传统 RMSE|相对改进|Tab 覆盖率|
|---|---:|---|---:|---:|---:|
|smooth_n500_p50|0.0497|ensemble|0.0578|约 14.1%|0.94|
|smooth_n1000_p50|0.0351|ensemble|0.0378|约 7.0%|0.95|
|smooth_n1000_p100|0.0379|ensemble|0.0431|约 11.9%|0.91|

原因也能从干扰函数预测误差中看出来。以 smooth_n1000_p100 为例，TabICLv2-1 的平均误差乘积为 0.1465，而传统集成模型为 0.3276。DML 要求结果方程和处理方程两个干扰函数都估计得足够好；TabICLv2 在这里显著降低了这两个预测误差的联合影响。

计算成本差异很大：TabICLv2-1 每次约 4–5 秒，TabICLv2-8 约 9–15 秒，而传统集成模型约 21–62 分钟。因此 smooth 场景是最有力的正面证据。

### 2. 线性场景：TabICLv2 基本持平，但没有必要替代 Lasso

linear_n2000_p50 中：

- ensemble RMSE：0.0248；
- Lasso RMSE：0.0250；
- TabICLv2-1 RMSE：0.0250；
- TabICLv2-8 RMSE：0.0250。

四者精度几乎相同。TabICLv2 比传统集成模型快很多，但 Lasso 每次只需约 0.11 秒，比 TabICLv2 更简单、更快。因此在线性结构已知或近似成立时，没有充分理由用更复杂的 Tab 模型替换 Lasso。

### 3. 树型场景：TabICLv2 明显失败

|配置|最佳传统模型|传统 RMSE|TabICLv2-1 RMSE|TabICLv2-8 RMSE|Tab 覆盖率|
|---|---|---:|---:|---:|---:|
|tree_n2000_p10|XGBoost|0.0566|0.1000|0.1016|0.01|
|tree_n5000_p10|XGBoost|0.0438|0.0936|0.0963|0.00|
|tree_n5000_p50|Lasso|0.0712|0.1068|0.1157|0.00|

在前两个树型配置中，XGBoost 的 RMSE 大约只有 TabICLv2 的一半。TabICLv2 虽然对结果方程的预测误差较低，但对处理方程的预测并不够好。例如 tree_n5000_p10 中，TabICLv2-1 的 `l_mse` 为 0.1616，优于 XGBoost 的 0.1769；但它的 `m_mse` 为 0.1544，明显差于 XGBoost 的 0.0732。DML 依赖两个干扰函数共同工作，单独把其中一个预测得更准并不足以保证处理效应估计更好。

树型场景中不只是 TabICLv2 有问题：所有方法的 95% 置信区间覆盖率都远低于 0.95。最好的 XGBoost 覆盖率也只有 0.42、0.25 和 0.00。这说明这些配置下存在明显剩余偏差，常规 DML 标准误没有把偏差计算进去。因此这些场景中的区间推断不可靠，应作为实验的负面结果和方法局限重点报告。

## TabICLv2-1 与 TabICLv2-8

增加到 8 个估计器没有带来稳定改进：

- 7 个配置中，TabICLv2-8 相对 TabICLv2-1 的 RMSE 改进中位数为 -0.67%，即总体上略微变差；
- smooth_n1000_p50 中 TabICLv2-8 有小幅优势；
- 多数其他配置两者接近，树型配置中 TabICLv2-8 通常更差；
- TabICLv2-8 的运行时间通常是 TabICLv2-1 的约 2–4 倍。

因此当前结果不支持默认使用 8 个估计器。TabICLv2-1 更适合作为主要方案，TabICLv2-8 可作为稳健性或消融实验。

## 配对显著性检验

对每个配置、每个 Tab 模型和 5 个传统模型，比较同一次模拟中的处理效应平方误差，共进行 70 次配对检验，并采用 Holm 方法控制多重比较：

- TabICLv2-1：13 个比较显著优于传统模型，11 个比较显著劣于传统模型，11 个差异不显著；
- TabICLv2-8：14 个比较显著优于传统模型，12 个比较显著劣于传统模型，9 个差异不显著。

显著优势主要来自 smooth 场景以及相对较弱的传统基线；显著劣势主要集中在 tree 场景。这个结果进一步说明 TabICLv2 的收益具有明显场景依赖性。

## 论文中建议使用的表述

不建议写成“TabICLv2 全面优于传统机器学习方法”。更严谨的表述是：

> 在平滑高维非线性设计中，使用 TabICLv2 作为 DML 干扰函数学习器，相比调参后的传统集成方法将处理效应 RMSE 降低约 5%–14%，同时显著减少计算时间并保持接近名义水平的区间覆盖率。然而，这一优势不能推广到树型非线性设计；在树型设计中，XGBoost 的点估计更准确，且所有方法均出现严重欠覆盖。

## 局限性

- 结论来自合成的部分线性回归设计，不能直接推广到真实数据。
- Stage 2 只包含 Stage 1 选出的 7 个配置，不代表整个参数空间。
- 不同学习器的超参数搜索预算并不完全相同，运行时间应理解为当前实现下的成本，而不是算法的绝对速度。
- 结果 JSON 没有保存 Python 和依赖库版本，最后 16 条补跑结果无法仅凭文件严格证明依赖版本完全一致；批次一致性检验没有发现处理效应估计偏移。
- 树型场景的严重欠覆盖说明还需要进一步诊断 DGP、交叉拟合、标准误公式或更强的干扰函数学习器。

- `paired_comparisons.csv`：基于共享随机种子的配对检验和 Holm 校正结果。

- `rmse_by_config.csv`：各配置 RMSE 对照表。
- `stage2_accuracy_coverage_runtime.png`：准确率、覆盖率和运行时间总览图。
